# Куда пойти

Интерактивная карта интересных мест Москвы,
разработанная на Django.

## Возможности проекта

- Просмотр интересных мест на карте.
- Фотографии и описания локаций.
- Добавление мест через Django Admin.
- Сортировка фотографий перетаскиванием.

## Используемые технологии

- Python
- Django
- SQLite
- Leaflet
- TinyMCE

## Пример JSON-файла

Для загрузки новых локаций используется JSON-файл следующего формата:

```
{
  "title": "Антикафе Bizone",
  "imgs": [
    "https://example.com/photo1.jpg",
    "https://example.com/photo2.jpg"
  ],
  "description_short": "Краткое описание места",
  "description_long": "<p>Подробное описание места</p>",
  "coordinates": {
    "lng": "37.50169",
    "lat": "55.816591"
  }
}
```

Для загрузки локации используйте команду:

```
python manage.py load_place URL_JSON_ФАЙЛА
```
Команда загружает информацию о месте и его фотографии в базу данных.

## Установка и запуск

Клонируйте репозиторий:

``` bash
git clone https://github.com/VladUshakov97/where_to_go.git
```
Перейдите в папку проекта:

```bash
cd where_to_go
```
Создайте виртуальное окружение:

```bash
python -m venv .venv
```
Активируйте его в командной строке Windows:

```bash
.venv\Scripts\activate.bat
```
Установите необходимые библиотеки:

```bash
python -m pip install -r requirements.txt
```

## Настройка переменных окружения

Создайте файл .env в корневой папке проекта, рядом с manage.py.

Добавьте следующие переменные:

```
DEBUG=True
SECRET_KEY=ваш_секретный_ключ
ALLOWED_HOSTS=127.0.0.1,localhost
```
Для генерации секретного ключа используйте:

```
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```
Замените ваш_секретный_ключ на сгенерированное значение.

## Подготовка базы данных

Примените миграции:

```bash
python manage.py migrate
```
Создайте администратора:

```bash
python manage.py createsuperuser
```
Следуйте инструкциям в терминале.

## Запуск сайта

Запустите локальный сервер:

```bash
python manage.py runserver
```
Откройте сайт в браузере:

http://127.0.0.1:8000/

Административная панель доступна по адресу:

http://127.0.0.1:8000/admin/

## Назначение проекта

Проект предназначен для изучения Django, работы с базой данных, создания JSON API, настройки административной панели и интеграции готового фронтенда.

Сайт пока предназначен для локального запуска.
